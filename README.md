# Site com fotos de gatos

## Projeto testando API em sites

Site feito como trabalho de faculdade na disciplina de Programaçâo Web.

Tecnologias usadas:  
-HTML  
-Bootstrap  
-Vue.js  
-Axios  


O botão "Siiimmmm" adiciona uma imagem ou gif aleatório de uma API;  
O botão "Não" redirecioa para uma imagem de cachorro;  
O botão "Excluir" remove a primeira foto da lista, estilo FIFO.
